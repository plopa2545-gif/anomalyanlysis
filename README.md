# 위험률차손익 조기경보 · 2025년 4·5·6월

사용자가 제공하고 공개 저장소 포함을 승인한 2025년 4·5·6월 CSV 집계 데이터를 기본으로 표시합니다. 가상 사례와 합성 포트폴리오는 제거했습니다. 기본 집계 데이터는 HTML 안에 압축되어 포함되므로 별도 업로드 없이 파일을 열어 분석할 수 있습니다. 경보는 규칙 기반 후보이며 통계적 유의성이나 원인 확정을 의미하지 않습니다.

## 실행 및 배포

- 로컬: `python -m http.server 8080 --directory public`을 실행한 뒤 `http://localhost:8080`을 엽니다.
- Cloudflare Workers: 배포 권한이 있는 계정에서 `npx wrangler deploy`를 실행합니다. `wrangler.jsonc`에는 이 데모 전용 Worker 이름과 정적 파일 디렉터리만 지정되어 있으며, 기존 라우트나 도메인을 변경하지 않습니다.
- Git 연동 없이 업로드할 경우 Workers & Pages에서 **Upload static files**로 `public` 폴더를 새 Worker에 올립니다.

## 확인

`node test/smoke.cjs`로 포함된 데이터의 압축 해제, 월별 합계, 상세 탐색, 기본 데이터 복원을 검증합니다.

## PC에 있는 CSV로 분석

최신 Chrome 또는 Edge에서 `public/index.html`을 직접 열면 기본 데이터가 표시됩니다. **CSV 불러오기**로 다른 2025년 4·5·6월 파일을 선택하면 현재 탭의 데이터만 교체합니다. 교체한 파일은 서버에 전송되지 않으며, 새로고침·초기화·기본 데이터로 돌아가기를 실행하면 HTML에 포함된 기본 데이터로 복원됩니다.

로컬 분석 전 CSV 형식과 집계 중복을 확인하며, 3개 마감월과 A/B 경보 규칙을 사용합니다. 별도로 검증하기 전에는 이 기능의 계산 결과를 기존 기준 대시보드나 통계적 검정 결과와 동일하다고 해석하지 마세요.

CSV 엔진 수정 후 `node tools/embed-worker.cjs`로 단일 HTML에 반영합니다. `node tools/embed-worker.cjs --check`, `node test/csv-core.cjs`, `node test/smoke.cjs`, `node test/import-wiring.cjs`로 확인합니다. 외부 서버나 CDN은 필요하지 않습니다.

## 발표용 4·5·6단계

경보 후보의 상품명 또는 **보고서 보기**를 누르면 단계 이동 없이 **상품 점검 보고서**가 열립니다. 상품군·채널, 해당 상품의 속성 조합, 급부, 주계약·특약의 네 가지 비교와 A/B 각각의 3개월 선정 근거, 확인할 사항을 동일한 템플릿으로 표시합니다. 대표 경보 지점과 상품 전체의 부족액은 구분하며, 수치상 악화 지점을 실제 원인으로 단정하지 않습니다. 기존 단계 탐색은 보고서 하단의 **단계별 상세 분석**에서 사용할 수 있습니다.

- 4단계는 주계약·특약을 행, 세부급부를 열로 표시합니다. 코드 부족액·손익률, 코드 검색, 검토 목록 전체 보기를 제공하며 코드나 숫자 칸을 누르면 5단계로 이동합니다. 양의 코드 부족액의 누적 80%와 하위·전월 징후를 기본 목록에 포함합니다.
- 5단계는 왼쪽에 이번 달 경과구분(1차·2차·3차), 오른쪽에 같은 코드의 월별 변화를 표시합니다. 두 표 모두 부족액·손익률·위험보험료 순이며 좁은 화면에서는 세로로 배치합니다.
- 수치 칸을 선택하면 6단계의 종합 문구와 1~5단계 근거로 연결됩니다. 월별 칸은 해당 월로 분석월도 변경하며, ‘5단계 수치 다시 보기’는 원래 분석월로 돌아갑니다. 종합 문구를 복사할 수 있습니다.
- CSV의 관측된 0과 자료가 없는 월·경과를 구별합니다. 세부급부와 경과는 독립적인 분해이며 중복 합산하지 않습니다. 상품·채널·급부·코드와 선택 속성을 고정해 월별로 비교합니다.
- CSV 불러오기 및 데이터 초기화 후에도 선택한 블랙 테마를 유지합니다. 기본 집계 데이터는 공개 승인된 자료이며 HTML에 포함됩니다. 교체한 CSV는 현재 탭에서만 처리합니다.

배포본의 발표 화면 구조를 로컬 데이터에 맞춰 구현했습니다. 배포본의 Sources 연결 및 사전 검토 데이터는 복제하지 않으며 경보 수·순위의 동일성을 보장하지 않습니다.

`node test/presentation.cjs`는 4→5→6 탐색, 월 변경/복귀, 속성 범위, 관측된 0/자료 없음, 블랙 테마 유지를 검증합니다.

## 기본 데이터 재생성

공개가 승인된 CSV에 한해 `node --max-old-space-size=8192 tools/build-default-data.cjs <4월.csv> <5월.csv> <6월.csv>`를 실행합니다. 세부급부·경과 집계 및 관측 여부를 보존해 HTML에 압축 저장합니다. 원본 CSV 파일 자체는 저장소에 추가하지 않습니다.
